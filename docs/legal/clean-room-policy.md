# Clean-room policy

This policy is the operational core of BotW-PC's legal safety. It exists so
that contributors can study the game and build a port **without copying
Nintendo's protected expression** into this repository.

## Two outputs, strictly separated

1. **Analysis output** (what we record): facts about behavior and formats —
   "the executable at offset X reads structure Y", "field Z is a float angle
   in radians". Facts are not copyrightable.
2. **Repository code** (what we ship): original source written by
   contributors, informed by public knowledge and analysis facts.

## Never allowed in this repository

This includes analysis notes — not only code:

- Game code in any form: bulk disassembly, decompiler pseudocode, or
  decompiled source.
- Extracted assets: models, textures, animations, audio, fonts, text.
- Keys, tickets, certificates, or authentication material.
- Game files, or links to where game files can be obtained.
- Third-party code without a compatible license.

## Allowed

- Descriptions of behavior, memory layouts, offsets, and formats.
- Short illustrative excerpts (a handful of instructions) *only* when
  strictly necessary to explain a finding.
- Diagrams and tables authored by you.
- Original code and original test data (fixtures generated by your own
  tools).

## Mental checklist (before every commit)

1. Did I write this myself, or is it properly licensed?
2. Could this reduce someone's need to buy the game? (If yes → no.)
3. Does it contain raw bytes from the game? (If yes → no.)
4. Would a copyright lawyer call this clean? (If unsure → open an issue and
   ask first.)

## Roles and handoff

At hobby scale we cannot run two fully isolated teams. Instead we use a
**documented handoff**:

1. Analysis notes live in `docs/research/` as pure descriptions.
2. Implementation lives in `tools/` and `src/`, written from those
   descriptions plus public documentation.
3. Reviewers verify that implementation code was not copied verbatim from
   analysis notes beyond factual content.

If a PR blurs the line, it gets rejected — no hard feelings, policy wins.
