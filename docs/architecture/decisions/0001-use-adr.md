# 1. Use architecture decision records

- **Date:** 2026-10-18
- **Status:** accepted

## Context

We will make many hard-to-reverse technical choices (target platform,
translation vs reimplementation, rendering backend). The reasoning behind
them matters as much as the choice.

## Decision

Record every significant decision as a numbered ADR in this folder:
context, options, decision, consequences. Short and honest beats long and
polished.

## Consequences

Cheap bookkeeping; new contributors can read the "why" without archaeology.
Superseded decisions get marked instead of deleted.
