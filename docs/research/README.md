# Research notes

One file per investigation: `YYYY-MM-topic.md`.

Findings are **descriptions only** — no game code, no assets, no keys. See
[../legal/clean-room-policy.md](../legal/clean-room-policy.md).

## Template

```markdown
# <topic>

- **Date:** YYYY-MM-DD
- **Game version:** e.g. Wii U 1.5.0 / Switch 1.6.0
- **Tooling:** REA <version> + Ghidra <version> (PowerPC)
- **Contributor:** @handle
- **Source:** own copy, analyzed locally

## Question

What were you trying to learn?

## Findings

Facts: offsets, structures, behavior, with minimal excerpts.

## Evidence quality

Observed / derived / inferred / unknown — be explicit.

## Open questions

What remains unknown.
```
