## No game content in this repository

This repository contains **none** of the following, and contributors must
never add them:

- Game executables or archives (`*.rpx`, `*.wud`, `*.nsp`, `*.xci`, …) in any form.
- Extracted game assets (models, textures, audio, text, maps).
- Encryption keys, tickets, certificates, or any other access credentials.
- Verbatim decompiled/disassembled game code or code dumps.

All analysis affects only a contributor's own, legally acquired copy of the
game, performed locally on the contributor's machine.
